# 声音基准（听感采纳版）

**基准文件**：`audio/_listen/qwen3-0.6b_all12.wav`
**采纳者**：项目所有者，听感判定原话 ——
> "qwen3-0.6b_all12.wav 的语速和声音控制的都比较好，而且没有奇怪的杂音，
> 如果你需要一个基准的话，我觉得这个就很好"

今后任何引擎替换、参数调整、流程改动，都应以本文件为对照基准。

基准先在 12 段上采纳，随后在**全章 526 段（143 分钟音频）**上复验，结果为：

| 指标 | 12 段（采纳时） | **全章 526 段（复验）** | 差 |
|---|---|---|---|
| 声纹相似度 均值 | 0.7779 | **0.7778** | −0.0001 |
| 声纹相似度 标准差 | 0.0182 | 0.0202 | +0.0020 |
| 声纹相似度 最低 | 0.7514 | 0.6927（P1 0.7261） | −0.0587 |
| 6-9kHz 高频平坦度 均值 | 0.1241 | 0.1134 | −0.0107 |
| 6-9kHz 高频平坦度 最低 | 0.0954 | 0.0516 | −0.0438 |
| 段内停顿中位 | 0.42s | 0.400s | −0.020 |
| **质检不合格** | 0/12 | **0/526** | – |
| CER（whisper，去标点简体） | 10.65% | **9.65%**（中位 9.09%，最大 23.40%） | −1.00pp |

**关键：相似度均值在 20 倍规模上只差 0.0001**，说明 12 段的结论不是小样本幻觉。

- 电音指标最低：`seg363` 0.0516（仅 5.3s，短段方差大）、`seg188`/`seg323` 0.0602

## 三、三路横向对比（同批 12 段、同参考、同采样参数）

| 引擎 | 相似度↑ | 最低 | 6-9k平坦度 | CER↓ | RTF↓ | 听感判定 |
|---|---|---|---|---|---|---|
| **Qwen3-0.6B** | 0.7779 | 0.7514 | 0.1241 | 10.65% | 0.84 | ✅ **采纳为基准** |
| Qwen3-1.7B | 0.7648 | 0.7347 | 0.1047 | 10.70% | 0.81 | ⚠️ "有点快了"，且相似度反而更低 |
| LongCat-AudioDiT-1B | **0.8424** | **0.8252** | **0.0269** | **9.94%** | **0.25** | ❌ "电音有点严重，不如千问" |

### 关键结论

1. **Qwen3 升 1.7B 不值得做**：相似度 0.7648 < 0.7779（更差），速度没提升
   （批处理把参数量差异吃掉了），听感还偏快。省下 4.5GB 和一次改造。

2. **LongCat 被听感和指标双重否掉，尽管指标原本显示全胜**：
   - 它四项指标都最好（相似度 12/12 段全胜、分布与 Qwen3 完全不重叠）
   - 但听感判定"电音严重"。根因是 **6-9kHz 高频平坦度 0.027，只有人声(0.18~0.23)的 1/7**
     —— 高频被过度谐波化，缺少气声/齿音这类非周期成分，听感即周期性嗡鸣
   - **该缺陷与推理设置无关**：nfe 16/32/64、apg/cfg、引导强度 4.0→2.0，结果都停在 0.025 左右
   - 推测来自 Wav-VAE 的 11.7Hz 潜帧率（压缩 >2000 倍），属模型固有特性

3. **教训（已固化为指标）**：我最初把"6-9kHz 平坦度低"读成"更干净"，
   因为**从没量过真实人声的基准**。有了基准（人声 0.18~0.23）方向就反了：
   远低于人声 = 电音。该指标已加入 `quality.py::hf_tonality()` 与质检门。

   **门限标定（用全章 526 段数据定稳）**：

   | 来源 | 电音指标范围 |
   |---|---|
   | 真实人声 | 0.18 ~ 0.23 |
   | 本项目旧书稿（205字，60段） | 0.188 ~ 0.272 |
   | LongCat-AudioDiT-1B | 0.023 ~ **0.032**（最高） |
   | Qwen3-0.6B 全章 526 段 | **0.052**（最低）~ 0.156 |

   取 **0.04** = 两侧几何中点 (0.032×0.052)^0.5 ≈ 0.041，两边各约 1.25 倍余量。
   另加 `>=3s` 的最短时长门槛：实测最低值 0.0516 出现在一个 5.3 秒段上，
   短段该谱统计量方差偏大。
   最终判别：**全章 526 段 0 误报，LongCat 12/12 全抓**。

## 四、基准的可复现命令

```powershell
# 1. 生成（envs\qwen3tts）
python tts_eval\scripts\gen_qwen3.py `
  --model-dir Qwen3-TTS\pretrained_models\Qwen3-TTS-12Hz-0.6B-Base `
  --out qwen3-0.6b

# 2. 转写算 CER（envs\cosyvoice）
python tts_eval\scripts\transcribe.py --engines qwen3-0.6b

# 3. 四维度打分 + 汇总（envs\qwen3tts）
python tts_eval\scripts\score.py --engines qwen3-0.6b

# 4. 生成连续试听文件与逐句对照
python tts_eval\scripts\persegment_and_listen.py

# 5. 电音专项（可选）
python tts_eval\scripts\buzz_diagnose.py
python tts_eval\scripts\buzz_specificity.py
```

## 五、待确认

本基准是在**12 个连续段落**上采纳的。段长从 205 字砍到 105 字会让段数约翻倍
（第六章 249 → 526 段），整章听感是否与这 12 段一致，建议先重生成**一章**确认，
再推广到全书。
